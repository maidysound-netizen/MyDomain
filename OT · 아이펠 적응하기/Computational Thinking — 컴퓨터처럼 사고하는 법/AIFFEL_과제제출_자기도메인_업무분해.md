# AIFFEL 컴퓨팅 사고 과제: 자기 도메인 업무 분해 예시

## [도메인 맥락]

저는 **웹툰 외주 경력 9년**이 있으며, 현재 **타카코월드(TAKAKO WORLD)**를 기획·제작하는 1인 창작자입니다. 스토리·콘티·캐릭터 디자인부터 AI 그림 생성·수정, 컷 편집, 번역·레터링까지 관리하다 보니 **매주 웹툰 한 회차를 제작하는 반복 업무**에 많은 시간이 듭니다.

이를 해결하기 위해 **콘티·그림·검수·편집·제작 관리 담당 AI 에이전트 5개가 한 팀으로 협업**하는 제작 시스템을 만들고 싶습니다. 작품별 A·B·C·D팀으로 확장해 여러 웹툰의 정기 연재를 지원하는 것이 장기 목표입니다. **JSON 좌표 기반 다국어 번역·레터링 편집 도구는 이미 개발했으며, 멀티 에이전트 시스템은 앞으로 구현할 계획**입니다.

## [네 동작 분석]

**1. 분해(Decomposition):** 웹툰 한 회차 제작을 여섯 작업으로 나눕니다.

1. **자료 준비:** 작가가 스토리·캐릭터 설정을 제공하고 제작 관리 에이전트가 정리합니다.
2. **콘티:** 콘티 에이전트가 컷 수, 앵글, 표정, 장면 연출을 제안합니다.
3. **그림:** 그림 에이전트가 말풍선 없는 컷 이미지를 생성합니다.
4. **검수:** 검수 에이전트가 인체·의상·소품·캐릭터 일관성을 확인하고 오류 수정을 요청합니다.
5. **편집:** 편집 에이전트가 컷 순서·크기·여백을 조절해 세로 스크롤로 조립합니다.
6. **발행 준비:** 기존 JSON 번역·레터링 도구를 연동하고 제작 관리 에이전트가 최종 검토를 요청합니다.

**2. 패턴 인식(Pattern Recognition):** ① 매 회차 같은 제작 단계가 반복됩니다. ② AI 이미지의 손발·포즈·캐릭터 외형 오류가 반복됩니다. ③ 긴 스크롤 연출, 말풍선 꼬리 위치, 일본어·영어 번역과 레터링 수정이 반복됩니다.

**3. 추상화(Abstraction):** 작품별 차이는 설정 데이터로 관리하고, 모든 회차를 **`스토리·캐릭터 → 콘티 → 컷 이미지 → 검수 → 스크롤 편집 → 다국어 레터링 → 작가 승인`**이라는 공통 구조로 표현합니다.

**4. 알고리즘(Algorithm):** 매주 A팀의 새 회차 작업 시작 → 스토리·설정 확인 → 콘티 제안 및 작가 확인 → 이미지 생성 → 오류 검수 → **문제 있는 컷만 수정·재검수** → 세로 스크롤 편집 → 기존 JSON 번역·레터링 연결 → 작가 최종 승인 → 예약 발행 순으로 처리합니다. 재작업이 반복되거나 일정이 지연되면 제작 관리 에이전트가 보고하며, **미승인 회차는 발행하지 않습니다.** 같은 절차를 다른 작품팀에도 적용합니다.

## [출력 요구]

**한국어 마크다운 문서**로 회차별 제작 계획과 에이전트 담당 업무를 정리해 주세요. **컷 번호·장면·앵글·등장인물·대사로 구성된 콘티표**, 컷별 이미지 및 검수 결과, 세로 스크롤 편집 초안, 기존 JSON 다국어 레터링 연동 정보, 최종 승인 상태가 확인 가능해야 합니다.

## [검증 기준]

**총괄 창작자인 제가** 결과물을 검토하여 **“실제 한 회차 제작에 사용할 수 있다”**고 판단하면 통과입니다. 구체적으로 ① 주간 제작 일정에 맞는 회차 초안이 준비되었는지, ② 콘티·그림·검수·편집 결과에 누락이 없는지, ③ 캐릭터 외형·컷 흐름·대사 화자가 일치하고 주요 그림 오류가 수정되었는지, ④ 번역·레터링을 수정할 수 있는지, ⑤ 제 승인 없이 공개되지 않는지를 확인합니다. 미충족 항목은 해당 에이전트에게 재작업을 요청합니다.
